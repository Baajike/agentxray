Browser extension: a grade on every GitHub repo

An A to F badge appears next to the repo name on GitHub. Hover for the top findings, click for the full report. You see the risk before you click Clone. Works in Chrome, Edge, Brave and Arc.

Install: unzip, open chrome://extensions, turn on Developer mode, click Load unpacked, choose the folder.

Terminal

Zero dependencies. Scan a folder, or a GitHub repo without cloning it.

# scan the folder you're in
npx github:OWNER/agentxray .

# scan before you clone
npx github:OWNER/agentxray owner/repo

# see a full attack
npx github:OWNER/agentxray --demo
